For GitHub Copilot App, first-time setup is three guided actions. DSG pre-fills the marketplace, plugin, and Live prompt. You only confirm what GitHub shows you.

Add DSG to Copilot

Opens GitHub Copilot App with the DSG marketplace source already filled in.

Open Copilot · Add DSG
GitHub asks you to confirm. DSG cannot silently add a marketplace on your behalf.
2

Install DSG Governance

After the marketplace is added, this opens the plugin install form with dsg-governance pre-filled.

Open Copilot · Install DSG
The installed plugin uses the production Cinema MCP endpoint. No secret is embedded in the plugin package.
3

Start DSG Live

Paste the GitHub repository where your agent works. DSG opens a Copilot session with the Live kickoff prompt already filled in.

Example: acme/customer-support-agent
The kickoff asks the plugin to call DSG status, start an OBSERVE Live session, and return the private monitor link before the first governed action.
Why there are confirmations

GitHub intentionally requires the user to confirm marketplace and plugin installation. This page pre-fills those forms but does not bypass GitHub security. DSG Live can start in OBSERVE without a DSG API key; deployments that enforce paid/control access can require account authentication before ENFORCE or verified proof issuance.

Developer fallback
CLI remains available for engineers, but it is not the customer onboarding path. Plugin source: https://github.com/tdealer01-crypto/DSG-Cinema-Proof-Agent/tree/main/marketplace/agent-plugin
