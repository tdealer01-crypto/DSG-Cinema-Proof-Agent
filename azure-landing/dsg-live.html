DEFAULT · OBSERVE

Record without taking over the customer's runtime

Observe shows classification, reason, evidence, and audit state. A policy BLOCK stays a BLOCK in the governance record even when customer execution is not stopped by DSG.

  • Good for first integration and evaluation.
  • No silent BLOCK → ALLOW rewriting.
  • Evidence remains available for review.
OPT-IN · ENFORCE

Apply DSG's decision to execution

When enforcement is enabled, approved actions can proceed while out-of-plan or unauthorized actions can be stopped or held for permission.

  • Explicit opt-in.
  • Plan and permission checks remain deterministic.
  • Agent authority remains scoped and revocable.

Truth boundary

Replay verifies history; it does not secretly run production again.

Replay is verification only. It re-checks recorded inputs, evidence, hashes, and deterministic postconditions. It never re-sends the action merely because someone requested replay.
