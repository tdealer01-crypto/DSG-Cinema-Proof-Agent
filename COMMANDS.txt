TROUBLESHOOTING
────────────────

  "az: command not found"
    → Install Azure CLI: https://aka.ms/InstallAzureCLI

  "docker: command not found"
    → Install Docker Desktop: https://www.docker.com/products/docker-desktop

  "not authenticated"
    → Run: az login --tenant cbc618d5-9aa3-46b5-ae64-d07794603a7a

  "permission denied"
    → chmod +x EXECUTE_ROUND_1_AZURE.sh

  "Container not starting"
    → Check logs: az container logs --resource-group rg-t.dealer01-0468 --name z3-solver-service

  "Health check timeout"
    → Wait 30-60 seconds (container takes time to start)
    → Check: curl http://z3-solver-service.westus3.azurecontainer.io:8080/health

  "401 Unauthorized"
    → Verify API_SECRET from deployment output
    → Use: -H "Authorization: Bearer <SECRET>"
