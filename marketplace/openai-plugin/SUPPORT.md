# Support — DSG Verified Execution

Public support: https://github.com/tdealer01-crypto/DSG-Cinema-Proof-Agent/issues

When reporting a problem, include the plugin version, non-secret reproduction steps, the decision/status, and relevant proof/context hashes when safe to share. Never post API keys, tokens, passwords, solver secrets, or private customer data in a public issue.

Security-sensitive reports should use the repository's private vulnerability-reporting mechanism when enabled rather than a public issue.
