# Public listing

- **Plugin name:** DSG Verified Execution
- **Plugin identifier:** `dsg-verified-execution`
- **Publisher:** tdealer01-crypto / DSG publisher account; publisher identity must be verified in the submission organization before review.
- **Submission type:** Skills only
- **Suggested category:** Developer Tools
- **Short description:** Verify actions against approved plans with Z3 proof.
- **Long description:** Create a bounded execution-verification request from approved-plan and observed execution facts, send it to the DSG Cinema verification backend, and return an ALLOW, REVIEW, or BLOCK Proof Receipt only when the exact Z3 verifier reports `VERIFIED_GLOBAL_OPTIMUM`. Receipts include deterministic proof, request, and context hashes plus replay, evidence-completeness, and cost fields. The plugin fails closed when live verification is unavailable and does not expose solver credentials or accept arbitrary QUBO programs.
