# Support — DSG Governance Gate

Public support: https://github.com/tdealer01-crypto/DSG-Cinema-Proof-Agent/issues

Include the app version, sandbox/live mode, charge or PaymentIntent object type,
the displayed decision or error, non-secret reproduction steps, and shortened
proof/context hashes when safe. Never post full customer records, API keys,
passwords, OAuth tokens, webhook secrets, app signing secrets, or payment-card
data in a public issue.

For security-sensitive reports, use the repository's private vulnerability
reporting feature after confirming it is enabled. For privacy requests, email
[t.dealer01@dsg.pics](mailto:t.dealer01@dsg.pics) without including secrets.
